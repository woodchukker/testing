#### Innendørs:

Alle, foruten Trad, LB, W1 og OC, skyter trippel-skiver i match- og finalerunder \
Recurve Senior, 50+, U21 og U18 kan velge mellom full- eller trippelskive innledningsvis \
Barebow Senior kan velge mellom full- eller trippelskive innledningsvis \
BB, Trad og LB U18 kan sette rekord i egen aldersbestemt klasse, eventuelt i alderstrinnet over dersom skytter deltar i denne klassen.
