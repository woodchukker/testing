# Description
This project is to display [Norges Bueskytterforbund's](https://www.bueskyting.no) Laws and Rules in a readable format on mobile devices.

## Background
The present Laws and Rules format is pdf based, flat, unindexed and none searchable making it extremely difficult to read on anything other than a reasonably large screen.
This is frustrating when attending competitions, as a judge, not having the Rules readily at hand when needed.

## Solution
First converting the pdfs to word and then to markdown, reformatting them manually as they are also in a reasonably unstructured format.

Using [Astro Starlight framework](https://starlight.astro.build/) to provide readable, searchable and indexed set of Laws and Rules across all devices. \
Published on GitHub Pages:
https://woodchukker.github.io/testing/

### Disclaimer
The Laws and Rules published here are not maintained by NBF.
Always refer the NBF's official rules on their website:
https://www.bueskyting.no/p/63612/lover%2C-regler-og-retningslinjer
