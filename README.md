# Description
This project is to display Norges Bueskytting Laws and Rules in a readable format on mobile devices.

## Background
The present Laws and Rules format is pdf based, flat, unindexed and none searchable making it extremely difficult to read on anything other than a reasonably large screen.
This is frustrating when attending competitions as a judge, not having the Rules readily at hand.

## Solution
First converting the pdfs to word and then to markdown, reformatting them manually as they are also in a reasonably bad format.
Using Astro Starlight framework to provide readable, searchable and indexed set of Laws and Rules across all devices.
